# Project Standards

## Tech Stack
- Javascript
- Tailwind
- Firebase/Supabase
- React Query

## Code Standards
- No inline styles
- No massive components
- Components < 250 lines
- Service layer mandatory
- Use environment variables

## Git Workflow
- feature branches only
- descriptive commits
- no direct pushes to main

## AI Instructions
- Think deeply before implementation
- Ask before deleting major code
- Always preserve existing features
- Check for regressions

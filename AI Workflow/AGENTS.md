# Coding Rules

- Always analyze before coding
- Never modify unrelated files
- Explain architecture decisions
- Prefer reusable components
- Use Javascript everywhere
- Follow clean folder structure
- Use async/await
- Avoid deeply nested logic
- Write modular code
- Validate before finalizing
- Run tests after edits

# Frontend Rules

- Use Tailwind
- Use shadcn/ui
- Responsive by default
- Accessible components
- Reusable hooks
- If any good component available or library for required task then search and ask.

# Backend Rules

- Proper MVC/service structure
- Input validation everywhere
- Centralized error handling
- Environment variables only
- Secure APIs

# Workflow

1. Analyze
2. Plan
3. Explain plan
4. Implement
5. Test
6. Refactor
7. Summarize changes
